Python, limbaj interpretat

Un program Python (fișier .py) este executat de interpretor instrucțiune cu instrucțiune, fără un pas separat de compilare care să producă un fișier executabil (ca la C++). Consecință practică: o eroare de execuție de pe linia 20 apare abia când programul ajunge acolo; liniile de dinainte s-au executat deja. Erorile de sintaxă, în schimb, sunt semnalate înainte de execuție.

Primul program

# Comentariu: tot ce urmează după # este ignorat de interpretor
nume = input("Cum te numești? ")     # citește un text de la tastatură
print("Bun venit,", nume + "!")       # afișează pe ecran
  • Instrucțiunile se scriu câte una pe linie; nu se pun ; la final (se pot folosi pentru a scrie două instrucțiuni pe aceeași linie, dar nu se recomandă).
  • Indentarea (spațiile de la începutul liniei) face parte din sintaxă: ea arată ce instrucțiuni aparțin unui if, for, unei funcții. Convenția: 4 spații.
  • Python face diferența între litere mari și mici: Nume și nume sunt variabile diferite; Print nu există.

Cum folosești exercițiile din această pagină

  1. Citește enunțul și exemplul (intrare → ieșire).
  2. Scrie programul în editorul negru. Tab indentează, Enter păstrează indentarea, Ctrl+Enter pornește verificarea.
  3. Rulează cu intrarea – execută programul cu datele din caseta „Intrare”, ca să vezi ce afișează.
  4. Verifică – programul este rulat pe toate testele; dacă un test pică, vezi intrarea, ce se aștepta și ce a afișat programul tău.

Variabile = etichete

În Python, o variabilă este un nume (etichetă) legat de un obiect din memorie. Atribuirea x = 5 creează obiectul întreg 5 și leagă numele x de el. Variabila nu are un tip fix: x = "cinci" o leagă ulterior de un șir. Tipul îl are obiectul: type(x).

Identificatori: litere, cifre și _, nu încep cu cifră, nu pot fi cuvinte cheie (if, for, while, def, class, return, and, or, not, in, is, True, False, None…). Convenția: litere_mici_cu_underscore; constantele se scriu cu majuscule: PI = 3.14159 (prin convenție – Python nu le blochează).

Instrucțiunea de decizie: if, elif, else

Programa 5.A: instrucțiuni; capitolul 2: structura alternativă

La finalul lecției vei ști

  • formele if, if–else, if–elif–else
  • blocurile prin indentare și instrucțiunile imbricate
  • expresia condițională
  • cum alegi ordinea condițiilor
nota = float(input())
if nota >= 9:
    print("Foarte bine")
elif nota >= 7:          # se evaluează doar dacă prima condiție a fost falsă
    print("Bine")
elif nota >= 5:
    print("Suficient")
else:
    print("Insuficient")
  • După condiție urmează :, iar instrucțiunile blocului sunt indentate. Un bloc nu poate fi gol – se folosește pass dacă nu vrei să faci nimic.
  • La if–elif–else se execută cel mult o ramură: prima a cărei condiție este adevărată. Ordinea contează: dacă am începe cu nota >= 5, un 10 ar primi „Suficient”.
  • Python nu are switch clasic; se folosește lanțul elif (sau, din Python 3.10, match, care nu este cerut de programă).
  • Expresia condițională: semn = "pozitiv" if x > 0 else "nepozitiv".

Maximul a trei numere – trei variante

a, b, c = map(int, input().split())
# 1) cu if-uri succesive
m = a
if b > m:
    m = b
if c > m:
    m = c
# 2) cu funcția predefinită
m = max(a, b, c)
# 3) cu expresii condiționale
m = a if a >= b and a >= c else (b if b >= c else c)
Greșeli frecvente: if x = 5: (atribuire în loc de == – eroare de sintaxă); if x == 1 or 2: (mereu adevărat, pentru că 2 este „adevărat”; corect: x == 1 or x == 2 sau x in (1, 2)); compararea unui șir citit cu un număr (input() == 5 este mereu False).

Șabloane care trebuie știute pe de rost

n = int(input())
v = list(map(int, input().split()))    # cele n valori, pe o linie

s = 0                  # suma
cnt = 0                # câte sunt pare
mx = v[0]              # maximul: se inițializează cu PRIMUL element, nu cu 0
poz = -1               # poziția primei valori negative
for i in range(n):
    s += v[i]
    if v[i] % 2 == 0:
        cnt += 1
    if v[i] > mx:
        mx = v[i]
    if v[i] < 0 and poz == -1:
        poz = i
print(s, cnt, mx, poz)

def cmmdc(a, b):              # Euclid
    while b != 0:
        a, b = b, a % b
    return a

def prim(n):                  # încercare până la radical: O(√n)
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

def in_baza(n, b):            # din baza 10 în baza b (2..10)
    if n == 0:
        return "0"
    s = ""
    while n > 0:
        s = str(n % b) + s
        n //= b
    return s

def permutari(n):
    x, folosit = [], [False] * (n + 1)

        if len(x) == n:

def ciur(n):                        # toate numerele prime ≤ n
    prim = [True] * (n + 1)
    prim[0] = prim[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if prim[i]:
            for j in range(i * i, n + 1, i):
                prim[j] = False
    return [i for i in range(n + 1) if prim[i]]

def bule(v):                        # sortare prin metoda bulelor, cu oprire timpurie
    n = len(v)
    for k in range(n - 1):
        schimb = False
        for i in range(n - 1 - k):
            if v[i] > v[i + 1]:
                v[i], v[i + 1] = v[i + 1], v[i]
                schimb = True
        if not schimb:
            break

def prima_poz(v, x):                # prima poziție cu v[i] >= x (v sortat)
    st, dr = 0, len(v)              # răspunsul poate fi și len(v)
    while st < dr:
        m = (st + dr) // 2
        if v[m] < x:
            st = m + 1
        else:
            dr = m
    return st

class ContBancar:
    banca = "Banca Școlii"                 # atribut de CLASĂ (comun tuturor obiectelor)

    def __init__(self, titular, sold=0):   # constructorul
        self.titular = titular             # atribut public
        self._sold = sold                  # „protejat” – convenție: nu-l folosi din afară
        self.__pin = "0000"                # „privat” – redenumit intern _ContBancar__pin

    def depune(self, suma):
        if suma <= 0:
            raise ValueError("suma trebuie să fie pozitivă")
        self._sold += suma

    def sold(self):
        return self._sold

    def __str__(self):                     # folosit de print()
        return f"{self.titular}: {self._sold} lei"

class ContEconomii(ContBancar):            # clasă derivată
    def __init__(self, titular, sold=0, dobanda=0.05):
        super().__init__(titular, sold)    # constructorul clasei de bază
        self.dobanda = dobanda

    def aplica_dobanda(self):
        self._sold = round(self._sold * (1 + self.dobanda), 2)

    def __str__(self):                     # suprascriere (polimorfism)

class Fractie:
    def __init__(self, a, b):
        if b == 0:

Exemplu

Fișierul imprumuturi.txt

Ana Ion 10
Dan Amintiri 20
Ana Amintiri 3
Radu Ion 15
Dan Baltagul 7

Ieșire

3
Amintiri
Dan Radu
