Un algoritm este o succesiune finită de pași clari care transformă datele de intrare în datele de ieșire. Proprietăți: generalitate, finitudine, claritate (determinism), corectitudine, eficiență. Gândirea computațională înseamnă: descompunere, recunoașterea tiparelor, abstractizare, proiectarea algoritmului.

Complexitatea în timp

Numărăm câte operații elementare face algoritmul în funcție de dimensiunea n a datelor și păstrăm doar termenul dominant, fără constante: 3n² + 5n + 7 operații ⇒ O(n²).

Ordinea, de la cel mai rapid la cel mai lent: O(1) < O(log n) < O(√n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!). Un calculator face orientativ 10⁷–10⁸ operații simple pe secundă în Python (mai multe în C++); cu n = 10⁵, un algoritm O(n²) face 10¹⁰ pași – mult prea mult.

Trei tehnici care reduc complexitatea

  • Sume parțiale: s[i] = v[0] + … + v[i−1]; suma pe intervalul [a, b] este s[b+1] − s[a] în O(1) în loc de O(n).
  • Doi indici (two pointers) pe o listă sortată: unul de la stânga, unul de la dreapta.
  • Memorie suplimentară: liste de frecvențe, mulțimi, dicționare – testul „am mai văzut valoarea?” devine O(1).

Recursivitate și metoda Divide et impera

Programa cap. 4: metoda Divide et impera; cap. 3: sortarea prin interclasare, sortarea rapidă, căutarea binară

La finalul lecției vei ști

  • cum funcționează stiva de apeluri
  • schema Divide et impera: împarte – rezolvă – combină
  • sortarea prin interclasare și sortarea rapidă
  • recurența T(n) = 2T(n/2) + n ⇒ O(n log n)

La fiecare apel, parametrii și variabilele locale se pun pe stiva de apeluri; la return se revine în apelant, exact în punctul de după apel. O funcție recursivă are obligatoriu un caz de bază și apeluri pe probleme mai mici.

Divide et impera

  1. Divide: problema se împarte în subprobleme independente de același tip (de regulă în două jumătăți).
  2. Impera: subproblemele se rezolvă recursiv; cele elementare direct.
  3. Combină: soluțiile subproblemelor se compun în soluția problemei.
def interclasare(a, b):
    i = j = 0
    c = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            c.append(a[i]); i += 1
        else:
            c.append(b[j]); j += 1
    return c + a[i:] + b[j:]

def merge_sort(v):                      # O(n log n), stabilă
    if len(v) <= 1:
        return v
    m = len(v) // 2
    return interclasare(merge_sort(v[:m]), merge_sort(v[m:]))

def quick_sort(v):                      # O(n log n) în medie, O(n²) în cel mai rău caz
    if len(v) <= 1:
        return v
    p = v[len(v) // 2]
    return quick_sort([x for x in v if x < p]) + [x for x in v if x == p] + quick_sort([x for x in v if x > p])

print(merge_sort([38, 27, 43, 3, 9, 82, 10]), quick_sort([5, 1, 5, 0]))
[3, 9, 10, 27, 38, 43, 82] [0, 1, 5, 5]

De ce O(n log n)? Lista se înjumătățește de log₂ n ori; pe fiecare nivel, interclasările costă în total n ⇒ n · log₂ n.

Turnurile din Hanoi: pentru a muta n discuri de pe A pe C, muți n−1 pe B, discul mare pe C, apoi n−1 de pe B pe C ⇒ M(n) = 2M(n−1) + 1 = 2ⁿ − 1 mutări.

Metoda Greedy

Programa cap. 4: metoda Greedy

La finalul lecției vei ști

  • ideea alegerii optime locale
  • problemele clasice: spectacole, rucsac fracționar, plata cu bancnote
  • de ce greedy trebuie demonstrat și când nu funcționează

Metoda Greedy construiește soluția pas cu pas, alegând de fiecare dată elementul care pare cel mai bun în acel moment, fără a reveni asupra alegerii. Schema: se sortează candidații după un criteriu, apoi se parcurg și se adaugă fiecare candidat compatibil cu soluția parțială.

Este rapidă (de obicei O(n log n), din cauza sortării), dar corectitudinea trebuie demonstrată pentru fiecare problemă. Contraexemplu clasic: plata sumei 6 cu monede {1, 3, 4} – greedy alege 4 + 1 + 1 (3 monede), optimul este 3 + 3 (2 monede).

Metoda Backtracking

Programa cap. 4: metoda Backtracking; cap. 3: metode de generare sistematică

La finalul lecției vei ști

  • schema generală a backtracking-ului
  • permutări, aranjamente, combinări, submulțimi, partiții
  • condiții de continuare (validare) și tăierea ramurilor
  • ordinea lexicografică a soluțiilor

Backtracking construiește soluția x₁, x₂, …, xₖ element cu element. Pentru poziția curentă încearcă pe rând toate valorile posibile; dacă valoarea respectă condițiile de continuare, trece la poziția următoare; când valorile se epuizează, revine la poziția anterioară. Complexitatea este exponențială, dar condițiile de continuare taie multe ramuri.

Programarea dinamică

Programa cap. 4: metoda programării dinamice

La finalul lecției vei ști

  • subprobleme suprapuse și substructură optimă
  • cum scrii relația de recurență și ordinea de calcul
  • problemele clasice: subșir crescător maximal, rucsac 0/1, triunghi, subșir comun, drumuri în grilă
  • reconstituirea soluției

Programarea dinamică se aplică atunci când problema are substructură optimă (soluția optimă conține soluțiile optime ale subproblemelor) și subprobleme suprapuse (aceleași subprobleme apar de multe ori). Fiecare subproblemă se rezolvă o singură dată, iar rezultatul se memorează într-un tablou.

  1. Definește starea: ce reprezintă d[i] (sau d[i][j]).

class Nod:
    def __init__(self, info, urm=None):
        self.info = info
        self.urm = urm

class Lista:
    def __init__(self):
        self.prim = None
    def adauga_inceput(self, x):          # O(1)
        self.prim = Nod(x, self.prim)
    def adauga_final(self, x):            # O(n) fără pointer spre ultimul nod
        nou = Nod(x)
        if self.prim is None:
            self.prim = nou; return
        p = self.prim
        while p.urm is not None:
            p = p.urm
        p.urm = nou
    def sterge(self, x):                  # prima apariție a lui x
        if self.prim and self.prim.info == x:
            self.prim = self.prim.urm; return
        p = self.prim
        while p and p.urm and p.urm.info != x:
            p = p.urm
        if p and p.urm:
            p.urm = p.urm.urm
    def __str__(self):
        v, p = [], self.prim
        while p:
            v.append(str(p.info)); p = p.urm
        return " -> ".join(v) or "(vida)"

from collections import deque

def bfs(L, s, n):
    dist = [-1] * (n + 1)
    dist[s] = 0
    q, ordine = deque([s]), []
    while q:
        x = q.popleft(); ordine.append(x)
        for y in L[x]:
            if dist[y] == -1:          # nevizitat
                dist[y] = dist[x] + 1
                q.append(y)
    return ordine, dist

def dfs(L, x, viz, ordine):
    viz[x] = True; ordine.append(x)
    for y in L[x]:
        if not viz[y]:
            dfs(L, y, viz, ordine)

Drumuri minime: Dijkstra, Roy-Floyd și Roy-Warshall

Programa cap. 3: algoritmul lui Dijkstra, algoritmul Roy-Floyd, algoritmul Roy-Warshall

La finalul lecției vei ști

  • Dijkstra pentru drumuri minime de la o sursă (costuri nenegative)
  • Roy-Floyd pentru toate perechile

import heapq
def dijkstra(L, s, n):                  # L[x] = [(y, cost), ...]
    INF = float("inf")
    d = [INF] * (n + 1); d[s] = 0
    pq = [(0, s)]
    while pq:
        dx, x = heapq.heappop(pq)
        if dx > d[x]:
            continue                    # intrare veche, deja îmbunătățită
        for y, c in L[x]:
            if d[x] + c < d[y]:
                d[y] = d[x] + c
                heapq.heappush(pq, (d[y], y))
    return d

Varianta clasică din manuale, fără heap: de n ori se alege nodul nefixat cu distanța minimă, se fixează și se relaxează muchiile lui – O(n²). Cu heap: O(m log n). Nu funcționează cu costuri negative.

def roy_floyd(d, n):                  # d = matricea costurilor, INF unde nu există muchie, 0 pe diagonală
    for k in range(1, n + 1):           # k – nodul intermediar, OBLIGATORIU bucla exterioară
        for i in range(1, n + 1):
            for j in range(1, n + 1):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]

def roy_warshall(a, n):                 # a = matricea de adiacență (0/1)
    for k in range(1, n + 1):
        for i in range(1, n + 1):
            for j in range(1, n + 1):

Arborele parțial de cost minim: Prim și Kruskal

Programa cap. 3: algoritmul lui Prim, algoritmul lui Kruskal

La finalul lecției vei ști

  • ce este un arbore parțial de cost minim (APM)
  • algoritmul lui Kruskal cu structura union-find
  • algoritmul lui Prim
  • de ce ambele sunt algoritmi greedy

Pentru un graf neorientat, conex și ponderat, un arbore parțial păstrează toate cele n noduri și n − 1 muchii, fără cicluri. Cel de cost minim are suma costurilor minimă (de exemplu, cablarea cea mai ieftină a unor clădiri).

def kruskal(n, muchii):               # muchii = [(cost, x, y), ...]
    tata = list(range(n + 1))
    def rad(x):                         # rădăcina mulțimii lui x (cu comprimarea drumului)
        while tata[x] != x:
            tata[x] = tata[tata[x]]
            x = tata[x]
        return x
    cost, alese = 0, []
    for c, x, y in sorted(muchii):      # muchiile în ordinea crescătoare a costului
        rx, ry = rad(x), rad(y)
        if rx != ry:                    # nu formează ciclu
            tata[rx] = ry
            cost += c; alese.append((x, y))
    return cost, alese

Prim: pornește dintr-un nod și adaugă repetat cea mai ieftină muchie care leagă arborele de un nod din afara lui (cu heap: O(m log n)). Kruskal: sortează muchiile și le adaugă pe cele care nu închid un ciclu (O(m log m)). Când costurile sunt distincte, APM este unic și ambii algoritmi îl găsesc.

  • Arbore = graf conex fără cicluri; n noduri ⇒ n − 1 muchii. Cu rădăcină se memorează prin vectorul de tați: tata[rad] = 0. Frunzele sunt nodurile care nu apar în vector. Nivelul (adâncimea) unui nod = numărul de muchii până la rădăcină; înălțimea = nivelul maxim.

def vigenere(text, cheie, semn=1):          # semn = -1 pentru decriptare
    rez, j = [], 0
    for c in text:
        if c.isupper():
            d = ord(cheie[j % len(cheie)]) - 65
            rez.append(chr((ord(c) - 65 + semn * d) % 26 + 65)); j += 1
        else:
            rez.append(c)
    return "".join(rez)

def fletcher16(octeti):
    s1 = s2 = 0
    for b in octeti:
        s1 = (s1 + b) % 255
        s2 = (s2 + s1) % 255
    return s2 * 256 + s1
